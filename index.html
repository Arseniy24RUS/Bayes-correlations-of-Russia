    Методика расчёта

    Корреляции рассчитаны по байесовской корректировке коэффициента Пирсона, описанной в corr.py. Для каждой пары показателей из исходной базы берутся ряды значений по региону, удаляются пропуски, затем вычисляется стандартный коэффициент Пирсона r. Байесовская поправка снижает смещение при малых выборках: rbayes = r · (1 − (1 − r²)/(n − 2)), где n — число наблюдений пары.

    Для подготовки корреляционных матриц удалены строковые столбцы, оставлены только числовые показатели, исключены константные признаки и столбцы с долей пропусков > 70%. Далее формируется квадратная матрица корреляций, где диагональ r = 1 не используется при визуализации. Все значения |r| ≥ выбранного порога отображаются в таблице и на графиках.

    Библиотеки и окружение: расчёты выполнялись в Python с использованием pandas, numpy и openpyxl; на странице применяется Pyodide для чтения Excel и Plotly для визуализаций. Готовый файл corr_all_regions_all.xlsx содержит отдельный лист для каждого субъекта РФ с сохранённой матрицей корреляций.
