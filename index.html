Дашборд визуализирует готовые байесовские корреляции социально-экономических и демографических показателей по каждому региону России на основе файла corr_all_regions_all.xlsx.

    Тепловая карта матрицы корреляций

    Ярко-красные значения соответствуют сильным положительным связям, тёмно-синие — сильным отрицательным. Диагональ r = 1 опущена из анализа пар.

    3D-облако значимых корреляций

    Каждая точка — пара показателей, координаты по осям соответствуют их индексам в матрице, вертикальная ось — величина коэффициента r.

    Методика расчёта корреляций и формирования базы

    Корреляции рассчитаны на основе модифицированного коэффициента Пирсона с байесовской поправкой, реализованного в скрипте corr_bayes_rf.py. Для каждой пары показателей из исходной базы берутся ряды значений по региону, удаляются пропуски, затем вычисляется стандартный коэффициент Пирсона r. Байесовская поправка снижает смещение при малых выборках и задаётся формулой rbayes = r · (1 − (1 − r²)/(n − 2)), где n — число наблюдений пары.

    На этапе подготовки данных для каждой территории удаляются строковые столбцы, оставляются только числовые показатели, исключаются константные признаки и переменные с долей пропусков более 70 %. Для каждого региона формируется квадратная матрица корреляций, которая сохраняется в отдельном листе файла corr_all_regions_all.xlsx вместе с краткой метаинформацией (число наблюдений, число переменных, период наблюдения).

    На данной странице браузер с помощью библиотеки SheetJS читает Excel-файл целиком на стороне клиента, без серверной части и без интерпретатора Python. Далее матрицы для выбранного субъекта РФ парсятся, строятся ранжированные списки корреляций, тепловая карта и трёхмерное облако точек с использованием Plotly.
